01 / THE IDEA

Stable context.
Evolving computation.

Looped Transformers gain effective depth by applying shared layers repeatedly. But repeating the entire stack places context construction and state refinement inside the same recurrent computation.

AsymLoop separates these roles. A causal encoder runs once and creates layer-specific Global key–value caches. A weight-tied decoder iteratively refines its state, reading both the fixed encoder context and its current Local KV through joint attention. All components are trained end to end.

02 / THE ARCHITECTURE

Encode once.
Refine recurrently.

A single-pass causal encoder.
A shared recurrent decoder.
A persistent connection between them.

01

Build the context

The causal encoder processes the input once. Per-layer projections create the Global KV caches used by the decoder.

02

Read both sources

Each decoder query attends to fixed Global KV and evolving Local KV under a shared softmax. Both sources retain causal masking.

03

Refine the state

The same decoder weights run across K iterations. Context stays available while the intermediate representation changes.

Inside joint attention+
A = softmax( [QKGT | QKLT] / √dh + [M | M] ) [VG ; VL]

The two KV sources are concatenated along the key-position axis. A query at position i can only access positions j ≤ i in either source. QKNorm followed by RoPE is applied to queries and keys.

How are the models compared?+

For L physical layers, AsymLoop executes L/2 encoder layers and K iterations of L/2 decoder layers. Its effective depth is (K+1)L/2. AsymLoop K=3 and Full Loop K=2 therefore both execute 2L layers.

The main comparisons match effective depth and training token budget within each nominal tier. Global KV projections and joint attention add parameters and FLOPs, so this is not a parameter- or compute-matched comparison. Each reported endpoint uses one training seed.

The 60M budget is 1.68B input positions including padding; the larger tiers use 3B, 7B, and 20B supervised tokens. Validation at 60M uses historical native aggregation; larger tiers use strict token-weighted aggregation.

04 / UNDER THE HOOD

Two sources.
Complementary roles.

What happens when the decoder loses one of its information sources? At the 60M tier, removing either Global KV or Local KV increases validation perplexity at both recurrence counts.

These architectural ablations use uniform learning rates and the same 10-million-supervised-token validation prefix after 3,200 training steps. They isolate components within this setting.

A

Learning rates follow the spectra.

We apply the heavy-tail-guided layerwise learning-rate method of He et al. to both components, calling this configuration ALRS. The same allocation rule applies throughout; measured spectra produce the differences between encoder and decoder.

B

Make the compute trade-off visible.

AsymLoop uses more training FLOPs than the original Full Loop at equal effective depth. The paper reports analytical matrix FLOPs alongside downstream accuracy, and separately evaluates a widened Full Loop at matched analytical per-step FLOPs.
